# MarketPulse AI – Stock Price Prediction Dashboard

An AI-powered stock market analytics and price prediction web application built using Python, Flask, Machine Learning, and Chart.js.

MarketPulse AI analyzes historical stock market data and uses deep learning models to estimate future stock prices through an interactive dashboard.

## Project Overview

Stock market analysis involves studying historical price movements and identifying patterns that may help understand market trends.

MarketPulse AI provides a web-based platform to visualize historical stock prices, compare actual and predicted values, and explore machine-learning-based forecasting.

## Key Features

- **Stock Market Data:** Fetch historical stock data using Yahoo Finance.
- **Stock Selection:** Analyze selected stocks and market indices.
- **Price Visualization:** Interactive charts for historical stock prices.
- **AI-Based Prediction:** Forecast stock prices using deep learning.
- **Model Comparison:** Compare LSTM, GRU, 1D CNN, and Transformer approaches.
- **Performance Evaluation:** Evaluate models using metrics such as MAE and R².
- **Prediction Dashboard:** Display latest closing prices and model estimates.
- **Interactive Interface:** View stock analytics through a Flask web application.

## Machine Learning Models

The project explores different deep learning architectures:

1. **LSTM (Long Short-Term Memory):** Learns long-term patterns in sequential stock data.
2. **GRU (Gated Recurrent Unit):** Uses a recurrent architecture to learn temporal patterns.
3. **1D CNN:** Extracts local patterns from time-series data.
4. **Transformer:** Explores attention-based learning for sequential data.

Model performance can be compared using evaluation metrics such as:

- Mean Absolute Error (MAE)
- R² Score

The best-performing model should be identified using actual evaluation results rather than assuming one model is always superior.

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/chitta123-code/MarketPulse-AI.git
cd MarketPulse-AI
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate on Windows:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

Navigate to the backend directory if `app.py` is located there:

```bash
cd backend
python app.py
```

### 5. Open in your browser

```text
http://127.0.0.1:5000/
```
